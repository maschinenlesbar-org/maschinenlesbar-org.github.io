This is the blog of maschinenlesbar.org. Here we'll write about the command-line tools
and TypeScript clients for open German public-sector APIs: new tools and releases, and
what we learn along the way about the APIs behind them.

Every tool, with its website and its Claude Code skills, is listed in the
[plugin marketplace](https://maschinenlesbar-org.github.io/plugins/). To try one right
away:

```bash
npm i -g @maschinenlesbar.org/tagesschau-cli
tagesschau homepage --compact
```

New posts appear in the [Atom feed](/feed.xml).
